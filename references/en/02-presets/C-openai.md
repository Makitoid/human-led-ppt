## C. OpenAI (restrained / neutral / technical authority)
- Look: paper-neutral ground + hairlines + generous whitespace, almost no ornament; lets numbers speak. Good for technical surveys, serious topics.
- Light: bg `#F7F7F5`, panel `#FFFFFF`, ink `#0D0D0D`, muted `#676767`, rule `#E5E5E3`, accent `#0A6E56` (body-safe, 5.8:1); brand green `#10A37F` is 2.98:1 — **large numerals and filled blocks only**
- Dark: bg `#0E0E0E`, panel `#171717`, elevated `#1F1F1F`, ink `#ECECEC`, muted `#A0A0A0`, rule `#2A2A2A`, accent `#1FCB9F`
- Type: `Söhne,Inter,-apple-system,"PingFang SC","Microsoft YaHei",sans-serif`; a mono face (`"JetBrains Mono",ui-monospace`) for headings adds technical flavour
- Rules: no shadows, radius ≤ 6px; charts in one colour plus a single accent; hierarchy from type scale and whitespace
- Motion / transition: cross-fade 350 ms only, no movement, no scale; the counting-up number is the only performance allowed. The restraint *is* the look.
- Helper skill: `frontend-design`; `agrimsingh-bringhurst-typography` if the type scale needs justification.
