## L. Dark terminal (CLI · trace · benchmark)
- Look: near-black blue, 56px hairline grid, CRT vignette and scanlines, `$ prompt` headings, mint glow on hero numerals.
- Signatures: ① traffic-light window chrome (a slide made to look like a terminal holding a trace) ② blinking caret `▍` (cover and closer only)
- Default partner: C OpenAI's restraint — drop the glow and this becomes a light deck
- Dark (primary): bg `#0A0C10`, panel `#11151A`, ink `#E6EDF3`(16.56), muted `#9AA4B0`(7.75), accent `#7ED3A4`(10.94), warn `#E0A94D`(9.27), rule `#1E252D`, accent-ink `#0B0B0B`(11.00)
- Light (degraded variant): bg `#F6F7F5`, panel `#FFFFFF`, ink `#12181D`(16.64), muted `#4E5A63`(6.59), accent `#0E6E4A`(5.84), warn `#7A5300`(6.38), rule `#DDE2E0`, accent-ink `#FFFFFF`(6.27)
- Type: `"JetBrains Mono",ui-monospace` for headings, numerals and code; Chinese body text goes to a sans — never set Chinese in a mono face
- Fits: terminal / code / diff / chart-bar (stroke-only bars) / verdict
- Motion: typewriter on at most one slide, bars drawn by `stroke`; `text-shadow` glow only above 64px
- Risk: scanlines + grid + glow together become mush on a projector — two of the three per page; mono Chinese is unreadable at body size
