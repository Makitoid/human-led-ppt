# 第 3 步 · 资料库与循证

只在用户要求搜集资料，或主题需要外部事实/数据支撑时执行。产出 `<主题>-资料总结.md`，它是第 4、5 步唯一的取数来源。

## 循证流程

1. **列检索计划**：按第 1 步的分幕，列出需要哪些数字（每页 1–4 个），标出"必须有原始出处"和"可以有方向无数字"两类。
2. **找原始出处**：优先一手来源 —— 论文原文（arXiv / 期刊页）、机构报告（IEA / UNEP / UNU / 政府网 gov.cn / 部委文件）、企业官方披露、官方新闻稿。媒体只作为定位线索和交叉印证，不作为最终出处。
3. **交叉验证**：关键数字至少两处独立来源。数值不一致时**两个都记**，写清口径差异，并标 ⚠️ —— 分歧本身就是可讲的内容。
4. **能打开才算核实**：用 `WebFetch` 实际读取页面；用 `WebSearch` 只得到摘要时，标 🔍。付费墙、403、反爬导致读不到正文时，标 🔍 并写明"经 X 镜像读取"或"仅二手支持"。
5. **外网打不开就说**：无法访问时，在资料总结里记一条 `⛔ 网络不可达：<URL>（<现象>）`，并在回复里明确告诉用户"由于网络原因无法访问，这条我没有核实"。不要改用记忆里的数字顶替，也不要静默跳过。
6. **禁止**：编造数字、编造 DOI/页码/链接、把估算写成定论、用"惊人""震撼"类形容词替代证据、把被误读的数字按误读版本引用（要引用就必须带上纠正）。

## 标记体系（全 deck 统一，HTML 里也要出现）

| 标记 | 含义 | 页面处理 |
|---|---|---|
| ⚠️ | 口径分歧 / 有争议 / 数字被误读过 | 必须同时给出分歧原因或纠正语 |
| 🔍 | 二手转引，未能一手核实 | 引用条保留，措辞用"据…转引" |
| ⛔ | 网络不可达，未核实 | **不得进入 HTML 正文**，只留在资料文件里 |
| （推算） | 由已有数据推得 | 页面上必须标注"我们据…推算" |

## 资料总结文件模板

```markdown
# <主题> · 资料总结与数据卡片

> 用途：<场合> 用资料。
> 采集日期：<YYYY-MM-DD>。所有数字均标注**年份 + 来源**。
> 标 ⚠️ = 有争议或口径不清；标 🔍 = 未能一手核实、属二手转引；标 ⛔ = 网络不可达未核实，禁止引用。

## 一句话地图
<这个议题的因果链条是什么，最大的方法论问题是什么。3–5 行。>

## 一、<分幕/分主题>
| 对象 | 数字 | 年份 | 来源 |
|---|---|---|---|
| <对象> | <带单位的数字> | <年份> | <作者或机构>，<定位信息> |
| <第二个对象> | <数字> | <年份> | <来源> |
| <有争议的值> | A 说 X，B 说 Y | <年份> | ⚠️ 写清口径差在哪 |

> 以上行是**格式占位**。把每个 `<…>` 换成带真实来源与年份的值；不要把示例数字留在文件里，也不要让方括号流进骨架或最终 deck。

**关键点，也最容易被讲错的地方**：
1. <同一研究自我修订 / 单位换算陷阱 / 常见误读及纠正>

## 二、…（同上，按幕分节）

## N、给 PPT 的结论弹药
1. **量级判断**：…  2. **归因判断**：…  3. **不确定性判断**：…  4. **行动判断**：…

## N+1、未核实缺口（课上/会上不要引用具体数字，只说方向）
<钴锂稀土量化数据、付费墙内的吨数……>

## 主要来源清单
- <机构/论文/报告全名>（<年份>）：<URL>  <读取情况：一手核实 | 经 X 镜像 | ⚠️ 原页 403 | ⛔ 网络不可达>
```

## 写作要求

- 每个数字带**年份**；跨年份的对比要写明是"存量还是增量""单点还是区间"。
- 单位统一并给出换算（MWh/GWh/TWh、加仑/升、吨/万吨），页面引用时保留原单位并注明换算。
- 主动收集"误读案例"和"自我修订案例"——它们比正确数字更有说服力，是天然的争议页素材。
- 结论弹药一节写给演讲者：4 条以内、每条是一个判断而不是一个数字。
- 资料总结与骨架、HTML 是同一套事实的三个视图。后续任何一步发现数据要改，**三份文件同步改**。

## 完成前自查

- [ ] 每个数字都有"来源 + 年份"，且能指向一个具体 URL 或文件名
- [ ] 关键数字有第二处印证，或已标 🔍
- [ ] 所有 ⚠️ 都写清了分歧在哪、怎么表述才不错
- [ ] ⛔ 条目没有流入后面的骨架/HTML
- [ ] 已把无法访问的链接明确告知用户
