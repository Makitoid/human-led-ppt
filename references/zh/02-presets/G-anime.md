## G. 二次元 / 动漫（活泼 / 强节奏 / 科普与社团）
- 观感：高饱和强调 + 粗描边卡片 + 网点与速度线，节奏快、情绪强。适合科普、社团分享、面向学生的讲解。**禁止使用任何受版权保护的角色形象**，只用抽象漫画语言（网点、对话框、集中线、拟声词块）。
- 浅色：bg `#FFF8F2`，panel `#FFFFFF`，ink `#1B1B2F`，accent `#D62246`（正文可用，4.78:1）；强调色块 `#FF4D6D`（3.05:1，仅限 ≥ 32px 大字与填充块），accent2 `#0E7C93`（正文）/ `#3AC0E0`（色块），warn `#8A6500`（5.06:1）/ `#FFB703`（色块），rule `#F2D8C8`，描边 `2px solid #1B1B2F`
- 深色：bg `#12122B`，panel `#1D1D3D`，ink `#FFF4EA`，accent `#FF6B85`（6.71:1），accent2 `#5AD1F0`（10.3:1），warn `#FFC94D`（11.95:1），rule `#2E2E57`，描边 `2px solid rgba(255,255,255,.85)`
- 字体：标题 `"Smiley Sans","思源黑体 Heavy","Noto Sans SC",sans-serif` 900 字重 + 负字距；正文 `"PingFang SC","Microsoft YaHei",sans-serif` 常规字重（正文别用粗体，会糊）
- 形状：卡片直角或 6px 圆角 + 硬投影（`4px 4px 0 <ink>`，无模糊）；对话框式标注、拟声词色块做强调
- 动效/切页：切页用**硬切 + 白闪 120ms**（`opacity` 层），或集中线从中心放射 200ms；页内元素用 `cubic-bezier(.34,1.56,.64,1)` 过冲弹出（scale .86→1），间隔 120ms；网点层做 8s 缓慢位移当背景。
- 借助 skill：`frontend-design`（市场里没有对应的网页美术风格 skill）；弹簧与过冲的时间曲线查 `web-animation-design`。
- 风险：硬投影 + 粗描边在投影仪上容易脏，务必实测对比度；每页强调元素 ≤ 3 个，否则变成噪声。
