# 第 2 步 · 风格方向

目标：定下一套可执行的设计决定，写进骨架 §1 的 `typography` / `theme` / `motion` / `禁止` 字段。**先讨论后落笔，本步不产出成品（HTML 或 PPTX）。**

## 先问三件事

1. 气质：给 2–3 个形容词或一张参考图（"像经济学人""像苹果发布会""像课堂笔记"）。
2. 主色：品牌色、院系 VI、或"你选"。有品牌规范时必须先索取，不要猜。
3. 禁区：明确不想要什么（渐变、玻璃、卡通、emoji、彩色图表、衬线字……）。

**背景**不在这三问里：默认是纯色底，只有用户点名要"整页照片／生成一张背景图"时才走 `background` 关键字（见 `04-skeleton.md` 与 `05-build.md`）。别替每一页都加背景——一是把 deck 撑大，二是背景一多正文对比度就守不住。

明暗不用单独问——每套预设都有浅 / 深两套色板，按场合选一套写进骨架（同一 deck **不得混用**）：课堂投影优先浅色，暗场 / 发布会 / 代码与数据密集优先深色。用户说"你决定"时，挑一套最贴主题的，说明理由，并留"随时可换"的余地。

## 可选辅助 skill

- 已安装且适用时，可用 `frontend-design` 做视觉决策、`material-3` 查组件规范；不要因选择预设而强制安装工具。
- 第三方 skill 名称是历史候选，非依赖。使用前核对可用性与正文；需要安装时先获用户确认。功能重叠的演示 skill 仅在用户询问替代方案时介绍。

## 视觉层级：先分主次，再谈风格

风格只决定"长什么样"，层级决定"第一眼看到什么"。一页显得乱，通常不是颜色不够多，而是有四五个东西在抢同一个位置。下面三组规则对任何预设、任何自定义风格都成立；预设自带更大字号的（如 O 的 160px 级标题、R 的杂志大标题），按预设比例整体放大即可，**层级数量和相邻级比值不变**。

### 1. 每页只留四档

| 级别 | 数量 | 是什么 | 字号（1280×720，可按预设整体放大） | 颜色 |
|---|---|---|---|---|
| 主语 | **恰好 1 个** | `key` / 一组 `kpi` / `pull`，三选一 | 48–60px；KPI 72–120px | ink，或唯一一块 accent 底 |
| 标题 | 1 个 | `h2`，本页叫什么 | 34px | ink |
| 支撑 | 2–4 个 | 论据、图表、步骤、卡片 | 22–24px | ink / panel |
| 细节 | 不限 | 眉标、图注、单位、来源 | 12–15px | muted（仍须 ≥4.5:1） |

- **主语只能有一个。** 两段文字都很大、两张卡都带强调色、标题和结论一样重——都是主语打架，必须重排，不是"再调调颜色"。没有 `key` 的页（封面 / 幕间 / 来源 / 致谢）例外：该页唯一的标题或内容块当主语。
- **同级同权。** 同一级的元素共用同一字号、字重、内边距和颜色；不得每张卡片都"稍微不一样"。要区分，只能把其中**一个**升级成主语，其余统一退回支撑级。
- **层级靠字号与留白，颜色只做定位。** 把稿子临时转成灰度，主语仍要第一眼可辨；如果去掉颜色就分不出主次，说明层级只挂在颜色上，回去改字号 / 字重 / 位置。
- **相邻层级的字号比 ≥ 1.4。** 默认阶梯 `48 : 34 : 24 : 14`（主语 : 标题 : 正文 : 注释）；`24 : 22 : 20` 这种阶梯等于没有层级。大字号预设整体放大时保持这套比值。
- **留白也是层级。** 页边 ≥ 56px，页头到正文 ≥ 28px，组间 ≥ 24px，组内 ≥ 12px；不得用分隔线、底纹或装饰把空白填满。

### 2. 强调色有预算

- **每页最多一处 accent 填充块**（色块、徽标、胶囊、整卡底色都算一处）；accent 是"看这里"的手指，不是页面底色。
- **每页最多一处 warn 标记**（一个风险段、一枚徽标或一条警示纹算一处）；warn 只表示风险 / 缺失，不表示"重要"。
- **第二强调色不上页。** 要用两种颜色区分两组信息时，先用分组、留白和字号；颜色是最后一步。
- **`emphasis` 必须落在主语上。** 强调色落在 12px 图注上等于没强调；一页出现两处同强度颜色，等于没有重点。

### 3. 对比度是层级的下限

- **所有承载信息的文字 ≥ 4.5:1**，包括正文、引用、图注、来源条；大字号（≥24px，或 ≥18.66px 粗体）≥ 3:1。
- **`--muted` 必须同时对 `--bg` 和 `--panel` 实测 ≥ 4.5:1。** 达不到就加深 muted，或用字号 / 字重退后；**不得用 `opacity` 压字**——透明度会把已经算好的对比度再打折。
- **带透明度的文字一律按实际合成色测**（`rgba(…,.6)`、`opacity:.6` 都算）；没测过就不得上。
- **accent 当文字色 ≥ 4.5:1；accent 当底时文字走 `--accent-ink` ≥ 4.5:1。** 品牌原色（OpenAI 绿、Fluent 蓝、Notion 灰）通常只有 2–3:1，只给大字或图形。
- **满版背景上的文字，按遮罩后最亮处测。** 测不过就加重遮罩，不得改正文颜色去迁就背景。

## 模板六条纪律

0. **一页一张背景就够，且必须压遮罩。** 满版背景（第三方照片或生成图）走 `background` 关键字，用 `data-bg` 铺一层底，上面再压可读的渐变遮罩；**背景图不得直接当 `<img>` 塞进正文流**（那是 `image` 关键字的事）。对比度守不住就先降背景亮度，别改正文色——详见 `05-build.md` 的背景层规则。

1. **颜色只住在 `:root`。** 页面 CSS 里除渐变端点外不应出现字面色值：`color:var(--ink)`、`background:var(--panel)`、`border:1px solid var(--rule)`。写死一处，换主题/换明暗就会漏一处（`05-build.md` 维护注意事项 8 就是这么来的）。
2. **accent 上的文字用 `--accent-ink`，永不写死 `#fff`/`#000`。** 强调色跨度可以近白到近黑，同一个字面值在不同主题下从 17:1 掉到 1:1（见 O 的实测）。每套模板都给了两套明暗各自的 accent-ink 与比值。
3. **一套主题 = 一套观感，一个 deck = 一套明暗。** 不得"封面用暗紫渐变、正文用奶油蓝图"。气质预设出 token，版式模板出骨架，签名件 ≤ 2/页。
4. **不发明新版式，先组合已有页型。** 页型名（`type`）控制在 6–8 种并复用；第 9 种版式出现前先问是不是某页只是内容太多。每页重画一套版式 = 总览墙认不出结构 + 构建必错。
5. **图片一律装框。** 框（`aspect-ratio` + `object-fit:cover`）决定比例与裁切，`<img>` 只负责填满——这样换任何尺寸的照片都不会顶版面。截图、图表、logo 一律 `object-fit:contain`（裁掉的就是信息）；满版照片压一层底部渐变遮罩（`linear-gradient(180deg,transparent 42%,rgba(8,10,20,.72))`）保证白字可读；框下一行 12–14px 图注。**没有装框的裸 `<img>` 不上页**。
6. **一页一个主语。** 同级卡片 ≤4 张，且只有一张可以带 accent 或放大一档，其余共用一套样式；三张以上同权并列就改用 `table` / `compare` 或拆页。装饰件总面积 ≤ 页面 15%，且不得挤进主语周围 1/3 的视觉热区。

## 自定义路线

用户自己设计时，按预设的字段结构逐项确认（观感 / 浅色板 / 深色板 / 字体 / 形状 / 规则 / 动效 / 风险），并调用 `frontend-design` 做视觉决策（配色关系、字体搭配、避免模板脸）；组件规范按需调用 `material-3`。用户给参考截图时，先量色值与字号层级再定案，不要凭印象。**"模板六条纪律"（含第 0 条背景规则）对自定义同样成立**：色值全进 `:root`、accent 上配 `--accent-ink` 并实测、只选一套明暗、页型 ≤ 8 种、图片装框、背景压遮罩、一页一个主语。

## 通用约束

- 正文 ≥22px，关键数字 72–120px 且用 `tabular-nums`；每页数字 ≤4。四档层级、强调预算和对比度按上文执行。
- 同步覆盖正文与总览令牌（含 `--ovl-bg / --ovl-ink / --ovl-card`）；深色用带色相的深灰，避免纯黑配纯白。
- 图表使用内联 SVG / CSS，不引图表库。签名件、页型、图片与背景按「模板六条纪律」执行。
- HTML 页内动效随切页播放；`prefers-reduced-motion` 时关闭。写明本稿的禁止项。

### PPTX 补充（target 含 native-pptx 时）

HTML 的 CSS 技巧不能直接搬到 PPTX；风格决定块要能被“原生对象”执行：

- **字体**：只用交付机已装的字体，标题/正文各写清 `latin` + `ea`（如 `Arial` + `Microsoft YaHei`）；不用网页字体、不嵌字体。缺字体会被 PowerPoint 替换，版式可能变。
- **页脚**：最小 10.5pt（HTML 的 9px 引用条不迁移）；所有承载信息的文字仍要 ≥4.5:1。
- **动效**：切页默认统一 `fade` 400ms，可按页换成 58 种 PowerPoint 效果之一（令牌写法与白名单见 `05b-pptx.md` §4）；页内动画按页声明，只挂得住 `shape` / `chart`（图片、表格、媒体挂不上），每页 ≤6 条、一次点击出一条。这里没有 CSS 缓动曲线可挑，只有 fast/med/slow 与 PowerPoint 预设。选哪几种、落在哪几页，在本步就写进风格决定块，不要留到构建时才决定。
- **形状与效果**：圆角、描边、阴影、发光用 PowerPoint 原生参数；预设要求“玻璃/折射/扫描线/半调”等 CSS 质感时，PPTX 用最接近的原生底/描边/透明度表达，并在风格决定块里写明“PPTX 近似”，不要承诺像素一致。
- **图表**：原生图表，2–12 类别、1–3 序列、线性轴；对数轴、瀑布、双单位这类先在风格块里标“PPTX 降级为表格/条形图”。
- **图片**：PNG/JPEG，单张建议 ≤2MB；满版背景必须配可读遮罩（构建器默认 55% 黑，可在块里调）。
- **禁止**：网页字体、CSS 滤镜、滚动/视差、自动播放音视频（除非用户明确要求）、把 PowerPoint 预设说成 CSS 级缓动效果。
