# 第 5 步 · 构建 HTML PPT

> `target` 含 `native-pptx` 时，本步改读 `05b-pptx.md`；下面只服务 HTML 主轨。

## 进入前

1. 骨架文件已获用户确认（第 4 步的卡点）。
2. 已读 `assets/deck-shell.css` 与 `assets/deck-shell.js`（**整段内联使用，不要重写一套导航逻辑**）。
3. 资料总结在手边，构建时逐页对照取数。
4. **读骨架时跳过 §4 开头的"词表注释"块**——从 `⧉ 词表注释 起` 直接跳到 `⧉ 词表注释 止`，中间一行都不读。那块是 §4 词库给人看的复制品，读它只是白烧上下文；真需要某个词的含义，回来查本说明书 §4 的表。页面上的 `- xxx: <!-- 注释 -->` 同理：只作对照，不产出 DOM。

## 冲突处理规则

严格照骨架 + 资料总结构建，**不擅自加内容**。发现骨架有问题时：

- **轻微**（标题措辞、页内顺序、视觉细节、字段缺失但可推断）→ 照骨架做，做完在骨架 §6 变更记录里注明实际情况。
- **严重**（数字与资料总结冲突、数字无出处、页面主张自相矛盾、把已纠正的误读又写回去了、页数/时长明显失控）→ 自行修正，并**同步修改骨架与资料总结**，三份文件保持一致；在最终交付说明里明确告诉用户改了什么、为什么。
- 需要新数据 → 回第 3 步补来源并写进资料总结，再填进骨架和 HTML；不要凭记忆填。

## 装配方式

单文件：`<style>` 与 `<script>` 全部内联，零网络请求、零 localStorage。以 `assets/deck-shell.html` 为起手模板——它里面留了两个 SHELL 占位符（用注释符号包着）——用附带的装配脚本内联，脚本会全局替换、校验没有占位符残留，失败时只输出一行原因：

```bash
node <skill目录>/assets/assemble.cjs deck.src.html <主题>.html     # --css <文件> / --js <文件> 可覆盖默认路径

# 需要第 7、8 步的叠加层时，装配时一并挂上（顺序固定：先 ink 后 presenter）
node <skill目录>/assets/assemble.cjs deck.src.html <主题>.html \
  --ink <skill目录>/assets/ink-overlay.html \
  --presenter <skill目录>/assets/presenter-overlay.html

# --ink / --presenter 也可以只写开关名，默认取装配脚本同目录下的同名文件
node <skill目录>/assets/assemble.cjs deck.src.html <主题>.html --ink --presenter
```

典型流程：把 `deck-shell.html` 复制成 `deck.src.html`，把三张示例页换成骨架里的真实页面，补上自己的主题 CSS，再跑装配脚本生成 `<主题>.html`。保留那份可编辑副本——已经内联了交互壳的文件很难手改。不要手工复制粘贴 CSS/JS：只要有一处占位符没替换干净，成品会安静地丢掉导航功能。改交互壳本身是低频操作；真改了，先 `node --check assets/deck-shell.js` 抓语法错误。

叠加层**不得**手写进 `<body>`：两个文件都靠装配器整段拼到 `</body>` 之前（用 slice/join 而非 replace，因为叠加层里带 `$`）。启用演讲者模式时先读第 8 步——它要求改两个配置块，并且提示词只能来自骨架 §7。

## DOM 契约

```html
<body>
  <div id="viewport"><div id="stage">
    <section class="slide" data-i="1">
      <header class="slide-head">
        <p class="kicker"><span class="act">……第二幕 · 小节名……</span></p>
        <h2>……本页标题……</h2>
        <p class="key">……本页唯一主张……</p>
      </header>
      <div class="slide-body">……数据区……</div>
      <p class="foot">……来源 · 年份…… <a href="……" target="_blank" rel="noopener">↗</a></p>
      <aside class="notes">演讲者备注，不显示</aside>
    </section>
    …
  </div></div>
  <div id="overview" role="dialog" aria-label="页面总览"></div>
  <div id="aria" aria-live="polite"></div>
  <div id="rotate-mask"><div class="ico"></div><p>请横屏观看</p><p class="sm">旋转设备后即可正常浏览</p></div>
</body>
```

类名约定（壳依赖）：`.slide` 必须是 `#stage` 的直接子元素；`.slide-head`（或 `.kicker` + `h1/h2`）决定总览缩略图露出什么；`.notes` 自动隐藏；`<span data-count="50" data-dec="1" data-pre="~" data-suf=" GWh">` 进页时从 0 递增。

`.notes` 的内容就是骨架 §7 那一页的提示词，**逐字搬过来**（`<strong>` / `<em>` / `<code>` 保留，演讲者窗的提示词卡只吃这一处）。没启用演讲者模式时它仍然是备注，听众窗口不显示、也不打印。

## 视觉层级：先定主语，再排内容

每页开工前先答一句：**这一页第一眼必须看到什么？** 答案只能是一个元素——`key` 那句话、一组 `kpi` 里的主数字、或一句 `pull`。其余内容按下面的阶梯排：

| 级别 | DOM | 字号（1280×720） | 字重 | 颜色 | 数量 |
|---|---|---|---|---|---|
| 主语 | `.key` / `.kpi` 主数字 / `.pull` | 48–60；KPI 72–120 | 700–900 | ink，或唯一一块 accent 底 | **1** |
| 标题 | `h2` | 34 | 600–700 | ink | 1 |
| 支撑 | `.slide-body` 的论点、图表、卡片 | 22–24 | 400–600 | ink / panel | 2–4 |
| 细节 | `.kicker`、图注、单位、`.foot` | 12–15 | 400–500 | muted，≥4.5:1 | 不限 |

先在 `:root` 写死四档字号，页面里只用这四档（预设整体放大字号时，四档按同一比例缩放，比值不变）：

```css
:root{
  --fs-claim:48px; --fs-title:34px; --fs-body:24px; --fs-meta:14px;
}
/* 比值 1.41 / 1.42 / 1.71；大字号预设按同一比值整体缩放 */
```

硬规则：

- **`.key` 是默认主语时，`h2` 固定在本稿的标题档（默认 34px）**，不得和 `.key` 同字号同字重；封面 / 幕间 / 来源 / 致谢这类没有 `key` 的页，`h2` 才可以当主语。
- **一组 KPI 最多 4 张，只有一张可以带 accent 或大一号**，其余同权；三个以上同权大数字等于没有重点，留一个主数字、其余进 `table`。
- **同级卡片共用一套 padding、圆角、字号**；强调只能落在**一张**上，其余不得换色。卡片栅格最多 4 张/行。
- **三栏以上必须打破等宽**：主栏 ≥ 1.4× 侧栏，或只给主栏 accent 底；三等宽 + 三色 = 噪声。
- **留白就是层级**：页边 ≥ 56px，页头到正文 ≥ 28px，组间 ≥ 24px，组内 ≥ 12px；不得用分隔线、底纹或装饰把空白填满。
- **装饰件总面积 ≤ 页面 15%**，且不得挤进主语周围 1/3 的视觉热区。
- **一页只有一处 accent 填充块、一处 warn 标记**；`emphasis` 必须落在主语上。第二强调色不上页。

## 版面基线（共享审美底线）

`hierarchy` 和上面的四档阶梯是第一顺位；下面是它们沉默时照做的底线。规则取自 ppt-master 的幻灯片设计规范，只搬规则、不搬它的 SVG 管线：

- **页面闭合**：成品 HTML 必须装下这一页所有可见的文字、图、形状与背景；不要指望壳或 CSS 事后补内容。
- **文字角色越少越好**：四档字号已经够用；区分角色靠字号 + 字重 + 颜色 + 位置 + 留白的组合，不得用 `24 / 22 / 20` 这种近似阶梯假装有层次。
- **行距按角色定**：标题 1.2–1.3×、密排小字 1.4–1.5×、正文 1.5–1.6×、大字或留白页 1.6–2.0×；不要为了塞下而把行距压穿。
- **按观看距离定密度**：先问"最后一排能不能读"，再决定放多少字；装不下就改写、拆页、换版式，不得偷偷缩字号或用 `opacity` 压淡。
- **对比与语义编码**：承载信息的文字必须和真实背景可分辨；新增区分优先靠明度、字重、大小、形状、位置或显式标签，颜色只能加强含义，不能单独承担含义。
- **自然换行**：在短语或标点处断行；末行可以短，但不得断出孤字。中英混排的空格与 `%` 写法按内容语言统一。
- **对齐与接近**：相关元素共用边缘、基线或中心轴；相关组比无关组更近。打破对齐轴必须是在表达层级、方向或张力。
- **视觉重量**：面积、明度、饱和度、密度、描边、图像细节一起估，不要只看颜色深浅；重量要支持视线落点，对称不是义务。
- **边界强度**：从留白/对齐、细线/括号、浅底，到描边、实心面板、真正的悬浮层——按关系选强度。同级关系用同一强度，层级或材质差异才换。
- **容器要有理由**：卡片/面板必须表达分组、层级、边界、容量或材质差；一排没有决策的"网页卡片"不是版式。
- **标题与页眉**：`h2` 是这一页构图的一部分，不是自动顶栏；只有承担导航、身份、署名或页码职责时才放常驻页眉/页脚。

## 媒体（图片 / 音频 / 视频）

骨架 §4 的 `image` / `audio` / `video` 三个关键字决定**文件放在哪**，落到 HTML 里只有三种写法。
**三种都由交互壳接管**：壳扫描 `[data-mp]`，注入控制条并延迟挂载源——**不要自己写 `controls`，
不要手写 `.mp-bar`**，写了你也和壳打两份架。

| 关键字 | 写什么 | 文件放哪 |
|---|---|---|
| `image` | `.img-frame` 里一个 `<img>`，`src` 写成 `data:image/...;base64,...` | 内联进 HTML，不产生外部文件 |
| `audio` | `<figure class="mp" data-mp><audio data-src="a.flac"></audio></figure>` | 与 `.html` **同目录**的同名文件 |
| `video` | `<figure class="mp" data-mp><video data-src="clip.mp4"></video></figure>` | 与 `.html` **同目录**的同名文件 |

```html
<!-- 视频：只有这两行，控制条由壳注入 -->
<figure class="mp" data-mp>
  <video data-src="demo.mp4"></video>
</figure>

<!-- 图片：base64 内联，仍是单文件 -->
<div class="img-frame">
  <img src="data:image/png;base64,iVBORw0KGgo…" alt="……必须写 alt……">
</div>
```

**满版背景（`background` 关键字）**：不是 `.img-frame` 里的 `<img>`，而是铺在 **`<section>` 自己身上**的一层底。壳读 `data-bg` 铺上去、读 `data-bg-scrim` 压遮罩，你只负责写属性 + 把这一页的内容抬到遮罩之上：

```html
<!-- 背景：只给 section 两个属性；内容容器必须抬到 z-index:1，否则会被背景和遮罩盖住 -->
<section class="slide" data-i="1"
  data-bg="data:image/jpeg;base64,…"
  data-bg-scrim="linear-gradient(180deg,rgba(8,10,20,.30),rgba(8,10,20,.72))">
  <header class="slide-head">…</header>
  <div class="slide-body">…</div>
</section>
```

```css
/* 这一页的内容整体抬一层；配合壳给 section 铺的底与 ::after 遮罩 */
.slide[data-bg] > *{position:relative;z-index:1}
```

- **只接受内联 data: 图片。** 写成 `https://…` 会被壳拒绝并在控制台点名那一页——deck 必须离线、单文件，背景也不能破例。
- **遮罩就是可读性的保险。** 上面有正文的满版图，几乎一定需要 `data-bg-scrim`；先按上例的深色渐变兜底，图很暗时才调浅。遮罩色也建议写进 `linear-gradient` 让 **底部更重**（白字多半压在下方）。
- **背景按整图算进文件大小。** 一张背景图只在**一页**用（别逐页复制同一张 data URL，见维护注意事项 17）；要贯穿全稿的底纹改用 `visual` 画 CSS 渐变色。图源与授权来自第 3 步的「候选图片」区，生成图先过 `draw`。

要点：

- **图片进 HTML，音视频不进。** 图片 base64 之后文件只大三分之一以内，拷走仍能看；音视频一旦
  base64，体积涨约三分之一，而 `file://` 下浏览器要先把这串字符解完才开始首帧——一个 30 MB 的
  片段会把开场卡住好几秒。壳因此把源延迟到**该页第一次出现**才挂，开场不会替没播的那一页下载。
- **`data-src` 是唯一入口**，壳读完就把它摘掉，避免同一个值在 DOM 里出现第二份真相。
- **控制条在画面下方，是卡片的一部分**，所以卡片的高度必须把条算进去：先量这一页还剩多少高度，
  再按"画面高 + 约 30px 条高"给 `.mp` 定死尺寸（音频卡没有画面，静止时只塌成一枚小喇叭，
  但**留高度要按展开后的条留**——鼠标一上去就该是完整的条，不得跳版）。
  **别用 `width:100%` + `aspect-ratio` 去撑高**——那条会被顶出 `.slide` 的裁剪框，画面看得见、
  条点不到（实测：1152 px 宽的 16:9 卡要 608 px 高，页头之下只剩 523 px，整条被推出去 85 px）。
  壳不会替你夹住它，这是构建错误；第 6 步有专门的可操作性断言。
- 缺文件不静默失败：**就在播放框里**写出「视频未找到」/「音频未找到」（`.mp-missing`，画面与控制条让位），
  更长的"把文件放在 .html 同目录"提示挂在 title 上。第 6 步要真跑一次这个分支。
- 打印时壳会 `display:none` 掉控制条，只留画面/占位；笔迹与提示词同样不打印。
- 交付说明里必须写清楚：这份 deck **不是**自包含的，音视频要连同文件夹一起拷走。

## 页面视觉规范

- **强调底上的字**：任何用 `--accent` 当底的块（徽标、胶囊、色带、封面大字），文字色一律走 `var(--accent-ink)`，**不得**硬写 `#fff` / `#000`——写死的那一次就是 1.01:1 的隐形文字（见第 2 步模板纪律）。
- **文字色只用四个令牌**：`--ink` / `--muted` / `--accent-ink` / `--warn`，页面 CSS 里不写 `rgba()` 文字色，也不用 `opacity` 把字压淡。要退后，用 `--muted` 或降字号，不用透明度。
- **`--muted` 对 `--bg` 和 `--panel` 都要实测 ≥ 4.5:1**；引用条、图注、单位、轴标签都算承载信息的文字，不能因为小就放过。大字号（≥24px，或 ≥18.66px 粗体）≥ 3:1。
- **满版背景上的字按遮罩后最亮处测**：遮罩后仍 < 4.5:1 就加重遮罩，不得改正文颜色去迁就背景。
- **图片**：一律包在带 `aspect-ratio` + `object-fit` 的容器里（`.img-frame` 之类），裸 `<img>` 不得出现；深底压浅图配 scrim，必须看全的图用 `contain` 并在容器里给底色。
- **密度**：每页 ≤ 4 个数字、≤ 4 张同级卡片；一页一个主语、一个主张（`key`）；其余进 `.notes`。页面上出现的每个数字，都必须能在该页 §4 里承载它的某个关键字中找到出处（`table` / `kpi` / `compare` / `formula` / `code` …）——关键字库与选词规则见 `04-skeleton.md` §4。
- **字号**：只用骨架 `hierarchy.scale` 的四档（主语 / 标题 / 正文 / 注释），相邻级比 ≥1.4；正文 ≥ `min_body_px`（默认 22px）；关键数字 72–120px 且 `tabular-nums`；引用条 9–11px 但对比度仍要能读。
- 证据链和来源页脚默认关闭。无论稿件类型，必须先询问作者并获得明确同意，才能将 `evidence_chain` 设为 `on`。未确认时，HTML 不加 `data-evidence="1"`，也不自动绘制来源引用条；原生 PPTX 不加任何角落的来源页脚。资料文件和备注继续保留来源，来源页只按已审核骨架生成。
- **满版背景**：`data-bg` 只给 `<section>`，内容抬到 `z-index:1`（见上）；背景图不进正文流、不装框，和 `image` 的 `.img-frame` 是两回事。
- **角色胶囊**：底部常驻；某角色"说话"时该胶囊描边 + 名字前加 `›`；一页最多两人说话。
- **图表**：内联 SVG / 纯 CSS，不引图表库。常用五种——对数条形（跨量级对比）、指数折线（2024=100，两线共起点，起点值并入 x 轴标签避免压线，图内注明"中间为线性示意走势"）、瀑布/台阶（自我修订叙事）、冰山对比（直接 vs 间接）、生命周期带（横向多段挂数据卡，问题段用 warn 色）。
- **图表与图示模板**：`assets/visual-templates.html` 提供 21 种模板（11 图表、10 图示）。复制一次 `<style data-viz-kit>`，再将所选 `<figure class="viz">` 放入 `.slide-body`；面板底加 `on-panel`。保留令牌、文字光晕与动画钩子，按时间、层级或流向选型。
- **外观与复制**：默认圆角；可加 `viz-outline`、`viz-blueprint` 或 `viz-editorial`，一图一种，可叠加 `on-panel`。外观不改数据尺度与连线语义。模板页支持分类、搜索、明暗预览和复制；复制会为内部 id 加后缀。手工复制同步重命名 `id`、`url(#…)`、`aria-labelledby`；控件和脚本不进 deck。
- **新增图表的尺度**：斜率图只比较两个时点；哑铃图两组端点共尺；子弹图的目标与当前值共尺；百分比堆叠每行合计 100%，不能推断绝对总量；气泡矩阵半径按 `sqrt(value/max)` 缩放且各列同口径；发散条保留零轴且左右等尺。每张模板的注释给出坐标公式，超出域时重设整条轴，不截断数据。
- **换数据**：同步修改文字、数值、单位、SVG 的 `<title>` 与数据对应的坐标 / 尺寸；按模板注释中的比例式重算几何，不只改标签。不动 `viewBox`、类名与 `pathLength`；数据点数量变了，按模板上方的比例注释重算坐标。对数条形的宽度必须按 `log10(value)` 算，不能拿原值当宽度；线性图表按模板里的比例式换算。模板里的数值是占位示例，构建时必须换成资料总结里的真实数字（硬规则 1）；单位、年份、估算/推算说明写全，`.foot` 写来源。
- **图示的强调与文字**：强调色只落在关键节点，warn 只落在风险节点；风险步骤用 warn 描边而不是填色，文字继续走 `--ink`。实色块里的字不加光晕（kit 已按 `.box-label` / `.box-sub` 直接命中 `<text>`），accent 底上的字走 `--accent-ink`；箭头用 `marker-end`，同一页复制多份模板时给 marker id 加后缀。
- **图表文字**：模板已内置与底色同色的描边光晕（`paint-order:stroke;stroke:var(--viz-halo);stroke-width:4px`），别删；轴标签走 `--muted`，对 `--bg` 与 `--panel` 都要 ≥4.5:1。

## 动画与切页

动效是演示纪律，不是装饰：默认只有一次交叉淡变，页内动画按需开。这套规则与 PPTX 轨同源（`05b-pptx.md` §4 的纪律表），只是落点从 `p:transition` 换成了 CSS。

- **切页默认交叉淡变**（壳：进 `.45s` / 出 `.3s`）。只有相邻两页的关系变了才换：同一节内的连续叙述保持淡变；直接切走用硬切；步骤 / 时间线 / 层级推进才用左右位移；章节开场或关键揭示才用一次更强的效果，且一节最多一次。不为"怕单调"换效果。
- **页内动画默认不加**，加就必须说得出它承担的沟通任务：按阅读顺序揭示（`riseIn` / 描线 / 计数），或让已可见的元素重新获得注意。背景、遮罩、页眉页脚、引用条默认不动；只有风格预设明确声明的背景氛围漂移例外（A / E / G / M 这类，幅度 ≤3% 视口），`prefers-reduced-motion` 时同样停。
- **一次揭示一组**：同一语义组（一张卡、一组 kpi、一段流程）默认一起进场，别让每个图标、每行字各飞一次；风格预设明确要求 stagger 时才逐项，且每页主动画元素仍 ≤6、不叠两层以上级联。
- **时长照风格预设，单条 ≤800ms**：超过 800ms 的入场比讲解慢，是拖累而不是强调；不要给正文 / 内容元素做循环动画（`infinite`）——那是"AI 感"的主要来源。
- **切页只改 `.slide` / `.slide.active` / `.slide.leaving` 的 `opacity` + `transform`**，不要用 `display` 做切页动画（总览缩略图靠 `display:block` 复原，用 display 会让缩略图变空白）。
- 页内实现照旧：条形 `width:0→终值`；折线 `stroke-dashoffset` 描线；卡片 `riseIn` 逐个上浮（间隔 0.2–0.35s，整组一起）；数字递增用 `data-count`。全部随切页自动播放、不依赖点击；重进某页要重播（`runCounters` 已按此处理，CSS 动画靠 `.active` 类重挂）。
- `prefers-reduced-motion` 时整体关闭（壳已内置，自定义 `@keyframes` 别写 `!important` 覆盖它）。
- **不自动播放媒体、不自动翻页**：现场讲就由人控节奏；展台循环属于另一种交付，要先跟用户确认。

## 链接

三种链接，三种落点。装配器在装配时逐个核对（`assets/assemble.cjs` 的 `linkErrors`），坏链接直接中止构建。

**1. 本地文件（骨架 `link` 关键字）**——点开后打开与 `.html` 同目录（或 `./assets/` 等子目录）的文件：

```html
<a class="file-link" href="./论文全文.pdf" target="_blank" rel="noopener">论文全文（PDF）</a>
```

- `href` 只能是**相对路径**：不要写 `C:\…`、`file:///…`，也不要用 `../` 逃出交付目录；文件名含空格写成 `%20`（或干脆用不带空格的名字）。
- 只链接真实存在、要一起交付的文件；`.html` 和这些文件放在同一文件夹，拷走时一起拷。
- `target="_blank" rel="noopener"` 必写：壳只接管 http(s)，本地文件交给浏览器自己打开；漏了 `target` 会把演示稿原地替换掉。
- `class="file-link"` 由壳提供样式（accent 下划线 + ↗），深色主题不必另写一套。
- 同一个文件在多页出现就多写一次 `<a>`，不要复制文件；也不要把文件 base64 塞进 HTML。

**2. 外链**——引用条、来源页、正文里的 http(s) 链接：

- 一律 `target="_blank" rel="noopener"`；壳用 `window.open` 兜底（内嵌预览器忽略 target），且点链接不触发翻页。
- 拿不到可验证 URL 的条目**不给链接**，并在资料总结里说明原因（付费墙 / 已下架 / 网络不可达）。
- 禁止 `javascript:` / `vbscript:` / `data:` 链接——装配器会直接判错。

**3. 页内跳转**——`href="#s5"` 走壳的 hash 路由，跳到第 5 页；不要指向不存在的页号，也不要用 `#` 当空链接。

## 维护注意事项

1. 缩放由 `fit()` 管；保留 `transform-origin:0 0`，不改成 translate 居中。
2. 切页用 opacity / visibility，不给 `.slide` 设 `display:none`，以免总览空白。
3. 在 `:root` 覆盖主题和总览令牌，不直接改壳的颜色。
4. 自定义交互控件需排除在点击翻页判定之外。
5. 后台标签页会暂停 rAF；数字动画用超时兜底落到终值。
6. 竖屏遮罩条件为竖屏且粗指针或短边 <600px；可用 `.show` 检查版式。
7. 拉丁字体栈须包含中文回退，如 PingFang SC / Microsoft YaHei。
8. 清除图表、徽标、描边、总览中的硬编码色值，防止深色残留浅色块。
9. 打印时重置 `#stage` 的定位与 transform，保证一页一纸。
10. 声明 viewport meta；壳已禁滚动，不给 body 另加滚动。
11. 叠加层可点击元素调用 `stopPropagation`，避免误翻页。
12. `?preview=N` 属于壳：不建总览、不写 hash、不翻页。画布尺寸同时更新 presenter 的 `CANVAS`。
13. 音视频只用壳注入的播放条，不加 `controls` 或第二套控件。
14. 媒体元素由 `.mp-el` 定尺寸；`.mp` 卡片高度须包含约 30px 播放条。
15. 音频卡不被 flex 拉伸；闲时约 36px、展开约 38px，播放条从喇叭向右展开，内容宽 416px。
16. 总览克隆中的媒体由静态 `.mp-ph` 替代；`[data-mp]` 只统计活播放器。
17. 每次复用内联图片或背景都会复制 base64；重复图形优先 `visual`，或减少图片复用。
18. 满版背景内容设 `position:relative;z-index:1`；`data-bg` 只接受内联 data: 图片。
19. 证据链按稿开启：`evidence_chain: on` → `data-evidence="1"`。无热键；徽标只汇总真实引用，不进打印。
20. 媒体缺失时在播放器内显示 `.mp-missing`，隐藏画面与控制条。
21. `h2` 与主语不能同为最大字号；主语唯一，标题退到第二档。
22. 弱化文字用 muted 令牌或字号，不用 opacity；对比度按实际合成色测。
23. 三栏并列时主栏宽度 ≥侧栏 1.4 倍，或只强调其中一栏，其余用 panel。
24. 本地文件链接需 `target="_blank" rel="noopener"`；装配器检查文件及协议。
