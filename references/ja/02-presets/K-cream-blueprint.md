## K. クリームの設計図（エンジニアリング · 印刷向き · グラデーションなし）
- 見た目：クリームの紙、低いアルファの 48px 設計図グリッド、2px の硬い罫線のカード、錆色のアクセント 1 色。壁に貼れる README のように見える。
- 署名の仕掛け：① グリッドの背景（表紙とアーキテクチャのページのみ）② 右端の錆色のインサイトコールアウトブロック
- 既定の相手：H 学術のグラフの作法、または A Fluent の秩序
- ライト：bg `#F0EAE0`, panel `#F7F3EA`, ink `#1C1A16`(14.52), muted `#5A554C`(6.18), accent `#B5392A`(4.90), warn `#7A5A12`(5.32), rule `#C9BFAE`, accent-ink `#FFFFFF`(5.86)
- ダーク：bg `#14171A`, panel `#1C2126`, ink `#E7E3D9`(14.04), muted `#A3A79F`(7.36), accent `#E4705D`(5.80), warn `#E0B95C`(9.65), rule `#2C333A`, accent-ink `#0B0B0B`(6.35)
- 書体：本文 `Inter,"Hiragino Sans","Hiragino Kaku Gothic ProN",sans-serif`；図中のラベルとコードネームは常に等幅；主役の数字は Playfair 級のセリフ体でよい
- 適合：arch-diagram / flow / process-steps / table / verdict
- モーション：`stroke-dashoffset` による線の描画、ボックスのフェードイン；**影ゼロ、角丸 0–2px、グラデーションゼロ**
- リスク：2px の罫線は 1px より投影機に強いが、1 ページのカードが 4 枚を超えるとスライドが方眼紙になる；暗い下地ではグリッドのアルファを半分に
