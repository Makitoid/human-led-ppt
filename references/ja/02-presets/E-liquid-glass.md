## E. Liquid Glass（Apple 2025 / 半透明 / ショーケース）
- 見た目：屈折する半透明のレイヤー、鏡面のエッジ、下を流れる内容；キーノートの熱量。**投影のリスクは現実**——低コントラストと細い書体は潰れる。
- ライト：下地の色面 `#EDEFF3 → #F7F4F0`（低コントラストのグラデーション、屈折のためだけ）、ガラス層 `rgba(255,255,255,.14)`、ink `#1D1D1F`、accent `#0B62B8`（本文可、5.28:1；システムブルー `#0A84FF` は 3.17:1、大きな文字のみ）、内側のハイライト `inset 0 1px 0 rgba(255,255,255,.45)`
- ダーク：下地の色面 `#0B0D12 → #141A24`、ガラス層 `rgba(255,255,255,.08)`、ink `#F2F5FA`、muted `#9BA6B5`、accent `#64D2FF`、ハイライト `inset 0 1px 0 rgba(255,255,255,.22)`、罫線 `rgba(255,255,255,.16)`
- 書体：`"SF Pro Display","Hiragino Sans","Hiragino Kaku Gothic ProN","Yu Gothic","Meiryo",system-ui,sans-serif`、見出しのトラッキング `-0.02em`
- 形状：角丸 24–32px；`backdrop-filter: blur(24px) saturate(180%)`
- モーション / 切り替え：屈折の入場——新しいページが 12px 下からフェードインし、下地の色面が 2–3% パララックスする；入場時にガラスのブラーを 40px → 24px へ締めてよい（表紙と幕間のみ）。性能に敏感：生きた `backdrop-filter` のレイヤーは 3 つを超えない。
- 補助スキル：設計原則と成果物／性能のレビューは `majiayu000-axiom-liquid-glass`；CSS は自分で導出する（あれは Swift 向け）。
- ハードルール：ガラス上の本文コントラストの実測 ≥ 4.5:1（スクリプトは `06-verify.md`）；失敗したら不透明度を上げる。ダークでは総覧の壁も暗くする。さもないとサムネイルのグリッドが白く光る。
