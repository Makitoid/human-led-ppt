## I. 遊び心（明るい / インタラクティブ / アイスブレイクとサークル）
- 見た目：キャンディ色のブロック + 非常に大きな角丸 + 手描きの輪郭 + 幾何学的な「顔」（インライン SVG の円、矢印、星——emoji のグリフではない）。アイスブレイク、イベント、軽い社内の場に向く。
- ライト：bg `#FFFCF5`, panel `#FFFFFF`, ink `#232323`；本文可 `accent #C24A2E` / `accent2 #007A70` / `accent4 #5A4BD1`；キャンディ原色 `#FF7A5C` / `#00B8A9` / `#FFC93C` / `#7B6CF6` は大きな文字と色面用；rule `#EFE6D8`
- ダーク：bg `#1A1725`, panel `#241F33`, ink `#FFF6EA`, accent `#FF8E70`, accent2 `#2FD8C4`, accent3 `#FFD75E`, accent4 `#9C8CFF`, rule `#38304D`
- 書体：見出し `"Smiley Sans","Source Han Sans JP Bold","源ノ角ゴシック Bold","Hiragino Sans","Hiragino Kaku Gothic ProN",sans-serif` 700–900；本文レギュラー；数字は主役として 140px まで大きくしてよい
- 形状：角丸 20–28px；硬い影または色付きのオフセット罫線（`box-shadow: 6px 6px 0 <accent>`）；ピルのチップ
- モーション / 切り替え：方向性のある `slide-left/slide-right`（350 ms、`cubic-bezier(.22,.61,.36,1)`）はここでは許容される；`popIn` は ±2° の傾きとオーバーシュート付き；押下状態は 4px 沈む。**注意**：固定 1280×720 のキャンバスでは、方向性のある切り替えは `opacity + transform` だけで行う——`display` は絶対に使わない。さもないと総覧のサムネイルが空白になる。
- 補助スキル：`frontend-design`；スプリングと押下フィードバックは `web-animation-design`。
- 注意：多色は最も制御を失いやすい——「主色 1 + 副色 2 + 中性色」までに抑え、1 ページの色相は ≤ 3。


> 各テンプレートが与えるのは**ページの骨子 + 署名の仕掛け 2 つ + 出発点のパレット**で、公式トークンではない。以下のパレットはすべて `06-verify.md` の ratio スクリプトで実測済み（本文 ≥ 4.5:1、括弧内の数字）；`accent-ink` は accent の塗りの*上*に載る文字の色で、独自の実測値を持つ。**どの値でも変更したらスクリプトを再実行する。**
> 使い方：テンプレートを選んだら、その 2 つの署名の仕掛けだけをこのデッキの `<style>` に書き、残りは気質プリセットに従う。署名の仕掛けは 1 ページ最大 2 つ——それ以上は装飾。
