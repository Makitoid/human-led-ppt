# ステップ 2 · ビジュアルの方向

目標：実行可能な設計判断を一式確定し、骨子 §1 の `typography` / `theme` / `motion` / `constraints` フィールドに書き込む。**まず議論、書き込みは後——このステップは完成品（HTML または PPTX）を産まない。**

## まず聞く 3 つ

1. 気質：形容詞 2–3 個、または参照画像 1 枚（「エコノミストっぽく」「Apple のキーノートっぽく」「授業ノートっぽく」）。
2. ブランドカラー：企業のパレット、部署の VI、または「任せる」。ブランドガイドラインがあるなら必ず求め、推測しない。
3. 禁止事項：明確に不要なもの（グラデーション、ガラス、カートゥーン、emoji、カラーチャート、セリフ体……）。

**背景**はこの 3 つの質問には含まれない：既定は無地の単色で、全面の写真や生成した背景をユーザーが求めたときだけ `background` キーワード（`04-skeleton.md` / `05-build.md` を参照）を使う。全ページに背景を足さない——デッキが重くなり、背景が増えるほど本文のコントラストを保てなくなる。

明暗は別に聞かない——どのプリセットも明 / 暗の両パレットを備え、デッキごとに 1 つ選んで骨子に書き込む（**同じデッキ内で混ぜてはならない**）：教室での投影は明色、暗い部屋・キーノート・コードやデータが密な場合は暗色。ユーザーが「任せる」と言ったなら、題材に最も近いプリセットを選び、理由を 1 行で述べ、入れ替えの余地を残す。

## 任意の補助 skill

- 導入済みで適切な場合は `frontend-design` を視覚判断、`material-3` を部品規約に使用。プリセット選択だけで導入を必須にしない。
- 第三者 skill は過去の候補で依存ではない。利用前に可用性と本文を確認し、導入はユーザーの同意後。重複するプレゼン skill は代替案を求められた場合のみ紹介。

## 視覚的階層：主従を決めてからスタイルを選ぶ

スタイルが決めるのは「どう見えるか」だけで、階層が決めるのは「最初の一目で何が目に入るか」である。1 ページが散らかって見えるのは、たいてい色が足りないからではなく、4 つか 5 つの要素が同じ場所を取り合っているからだ。以下はどのプリセットにも、自作のスタイルにも当てはまる；大きな文字サイズを持つプリセット（O の 160px 級の見出し、R の雑誌の大見出しなど）は、**段の数と隣り合う段の比率を変えずに**全体を同じ比率で拡大する。

### 1. 1 スライド 4 段階

| 段階 | 数 | 何か | 文字サイズ（1280×720、プリセットに合わせて全体を拡大可） | 色 |
|---|---|---|---|---|
| 主役 | **ちょうど 1 つ** | `key` / `kpi` の組 / `pull` の三択 | 48–60px；KPI は 72–120px | ink、または唯一の accent 塗り |
| タイトル | 1 つ | `h2`、このページの名前 | 34px | ink |
| 支え | 2–4 つ | 論拠、グラフ、手順、カード | 22–24px | ink / panel |
| 細部 | 制限なし | 眉標、図注、単位、出典 | 12–15px | muted（それでも ≥4.5:1） |

- **主役は 1 つだけ。** 2 つの文字がどちらも大きい、2 枚のカードがどちらも強調色を持つ、タイトルと結論が同じ重さ——どれも主役の取り合いであり、色を「もう少し調整する」のではなく組み直す。`key` を持たないページ（表紙 / 幕間 / 出典 / 謝辞）は例外で、そのページ唯一のタイトルまたは内容ブロックが主役になる。
- **同じ段は同じ権利。** 同じ段の要素は文字サイズ、字重、内側の余白、色を共有する；カードごとに「少しずつ違う」のは許さない。区別したいなら、**1 つだけ**を主役に上げ、残りは支えの段へ揃えて戻す。
- **階層は文字サイズと余白で作り、色は位置を示すだけ。** 稿を一時的にグレースケールにしても、主役は最初の一目で見分けられなければならない；色を外すと主従が分からないなら、階層が色にぶら下がっている——文字サイズ / 字重 / 位置に戻って直す。
- **隣り合う段の文字サイズ比 ≥ 1.4。** 既定の階段は `48 : 34 : 24 : 14`（主役 : タイトル : 本文 : 注記）；`24 : 22 : 20` のような階段は階層が無いのと同じ。大きな文字サイズのプリセットは、この比率を保ったまま全体を拡大する。
- **余白も階層である。** ページの余白 ≥ 56px、ページ頭から本文まで ≥ 28px、組と組の間 ≥ 24px、組の中 ≥ 12px；罫線、下地、装飾で空白を埋めてはならない。

### 2. 強調色の予算

- **1 スライドに accent の塗りブロックは最大 1 つ**（色面、バッジ、ピル、カード全体の下地も 1 つと数える）；accent は「ここを見る」指であって、ページの下地ではない。
- **1 スライドに warn の印は最大 1 つ**（リスクの段落 1 つ、バッジ 1 枚、警告の帯 1 本をそれぞれ 1 つと数える）；warn はリスク / 欠落だけを意味し、「重要」は意味しない。
- **2 つ目の強調色を載せない。** 2 色で 2 組の情報を分けたいときは、まずグループ化、余白、文字サイズで分ける；色は最後の手段である。
- **`emphasis` は必ず主役に落ちる。** 強調色を 12px の図注に落とすのは強調していないのと同じ；同じ強さの色が 1 ページに 2 つあるなら、重点は無い。

### 3. コントラストは階層の下限

- **情報を担う文字はすべて ≥ 4.5:1**（本文、引用、図注、出典バーを含む）；大きな文字（≥ 24px、または太字で ≥ 18.66px）は ≥ 3:1。
- **`--muted` は `--bg` と `--panel` の両方に対して実測 ≥ 4.5:1。** 届かないなら muted を暗くするか、文字サイズ / 字重で退かせる；**`opacity` で文字を薄くしてはならない**——透明度はすでに計算したコントラストをさらに割り引く。
- **透明度を持つ文字はすべて実際の合成色で測る**（`rgba(…,.6)` も `opacity:.6` も同じ）；測っていないものは載せない。
- **accent を文字色にするなら ≥ 4.5:1；accent を下地にするなら文字は `--accent-ink` で ≥ 4.5:1。** ブランドの原色（OpenAI の緑、Fluent の青、Notion のグレー）はたいてい 2–3:1 しかないので、大きな文字か図形にだけ使う。
- **全面背景の上の文字は、スクリム後の最も明るい点で測る。** 通らないならスクリムを重くする；本文色を背景に合わせて変えてはならない。

## テンプレートの 6 つの規律

0. **背景は 1 ページに 1 枚、しかもスクリムなしでは載せない。** 全面の背景（第三者の写真や生成画像）は `background` キーワードと `data-bg` レイヤーで敷き、その上に読めるグラデーションのスクリムを重ねる。背景を**本文の流れに `<img>` として差し込まない**（それは `image` の役目）。コントラストが保てないなら背景を暗くする——本文色を明るくしない。`05-build.md` の背景レイヤーの規則を参照。

1. **色は `:root` にだけ住む。** グラデーションの端点を除き、スライドの CSS にリテラルの hex を出さない：`color:var(--ink)`、`background:var(--panel)`、`border:1px solid var(--rule)`。1 つ書き込めば、テーマやモードの切り替えが漏れる場所が 1 つできる（`05-build.md` の保守上の注意 8 がまさにこれ）。
2. **accent の塗りの上に載る文字は `--accent-ink` を使い、`#fff`/`#000` は決して書かない。** アクセント色はテーマによってほぼ白からほぼ黒まで幅があり、同じリテラルが 17:1 から 1:1 まで振れる（O の実測を参照）。上のテンプレートはどれも、モードごとの accent-ink を実測値として載せている。
3. **1 テーマ = 1 つの見た目、1 デッキ = 1 つのモード。** 紫グラデーションの表紙の隣にクリーム設計図の本文ページを置いてはならない。気質プリセットがトークンを、レイアウトテンプレートが骨子を供給し、署名の仕掛けは 1 ページ ≤ 2。
4. **既存のページ種を組み合わせ、新しいものを発明しない。** 再利用する `type` の語彙は 6–8 に保ち、繰り返し使う。9 番目のレイアウトを設計する前に、そのページはただ内容が多すぎるだけではないかと問う。毎ページ版式を描き直すと、総覧の壁は読めなくなり、構築は誤りやすくなる。
5. **画像は必ず枠に入れる。** 枠（`aspect-ratio` と `object-fit:cover`）が比率とトリミングを持ち、`<img>` はそれを埋めるだけ——これによりどんな写真に入れ替えても版面が崩れない。スクリーンショット、グラフ、ロゴは常に `object-fit:contain`（切り取れば情報が消える）。全面の写真は下部にスクリム（`linear-gradient(180deg,transparent 42%,rgba(8,10,20,.72))`）を敷いて白い文字が読めるようにし、枠の下に 12–14px のキャプションを置く。**枠のない裸の `<img>` はスライドに載らない。**
6. **1 ページに主役は 1 つ。** 同じ段のカードは ≤ 4 枚で、accent を持つか 1 段大きくできるのはそのうち 1 枚だけ、残りは同じ様式を共有する；3 枚以上が同じ権利で並ぶなら `table` / `compare` に切り替えるか、ページを分ける。装飾の総面積は ≤ ページの 15% で、主役の周囲 1/3 の視覚的な熱区画に押し込んではならない。

## カスタム路線

ユーザーが自分で設計するときは、プリセットと同じフィールド一覧（見た目 / 明色パレット / 暗色パレット / 書体 / 形状 / 規則 / モーション / リスク）を順に確認し、判断は `frontend-design`（配色の関係、書体の組み合わせ、テンプレ的な見た目の回避）で進める。コンポーネント仕様は必要に応じて `material-3` を呼び出す。参考のスクリーンショットがあれば、決める前に hex 値と書体スケールを実測する——印象で作業しない。**テンプレートの 6 つの規律（背景ルール 0 を含む）はそのまま全部効く**：色はすべて `:root` に、`--accent-ink` は実測、モードは 1 つだけ、再利用するページ種は ≤ 8、画像は必ず枠に入れる、背景は必ずスクリムを敷く、1 ページに主役は 1 つ。

## 共通制約

- 本文 ≥22px、主要数値 72–120px と `tabular-nums`、数値は 1 ページ最大 4 個。階層・強調予算・コントラストは上記に従う。
- 本文と総覧のトークン（`--ovl-bg / --ovl-ink / --ovl-card` を含む）を揃える。暗色は色味のある濃灰を使い、純黒と純白を避ける。
- グラフは内蔵 SVG / CSS、ライブラリなし。署名要素・ページ型・画像・背景はテンプレートの 6 つの規律に従う。
- HTML の演出はページ進入時に動き、`prefers-reduced-motion` で停止。稿固有の禁止事項を記録。

### PPTX の補足（`target` に native-pptx を含むとき）

HTML の CSS の技はそのまま PPTX には移せない；スタイル決定ブロックは「ネイティブオブジェクト」で実行できる形にする：

- **書体**：納品先のマシンにインストール済みの書体だけを使い、見出し / 本文それぞれに `latin` + `ea` を明記する（例：`Arial` + `Yu Gothic UI`）；ウェブフォントは使わず、書体も埋め込まない。書体が欠けると PowerPoint が置換し、版面が変わりうる。
- **フッター**：最小 10.5pt（HTML の 9px の出典バーは移行しない）；情報を担う文字はすべて ≥4.5:1 を保つ。
- **モーション**：ページ送りは既定で一律 `fade` 400ms、ページ単位で PowerPoint の 58 種の効果に差し替えられる（トークンの書き方とホワイトリストは `05b-pptx.md` §4）。ページ内アニメーションもページ単位で宣言し、載せられるのは `shape` / `chart` だけ（画像・表・メディアは不可）、1 ページ ≤6 件でクリックごとに 1 件出現。ここには選べる CSS のイージング曲線は無く、fast/med/slow と PowerPoint プリセットのみ。どれをどのページに置くかは本ステップでスタイル決定ブロックに書く——構築時まで残さない。
- **図形と効果**：角丸、線、影、グローは PowerPoint のネイティブなパラメータで表現する；プリセットが「ガラス / 屈折 / 走査線 / ハーフトーン」といった CSS の質感を求めるなら、PPTX では最も近いネイティブの下地 / 線 / 透明度で表し、スタイル決定ブロックに「PPTX 近似」と明記する——ピクセル一致は約束しない。
- **グラフ**：ネイティブグラフ、2–12 カテゴリ、1–3 系列、線形軸；対数軸、ウォーターフォール、2 単位といったものは、まずスタイルブロックに「PPTX では表 / 棒グラフに降格」と書く。
- **画像**：PNG / JPEG、1 枚あたり ≤2MB が目安；全面の背景には読めるスクリムを必ず重ねる（ビルダーの既定は 55% の黒。ブロックで調整できる）。
- **禁止**：ウェブフォント、CSS フィルタ、スクロール / パララックス、音声・動画の自動再生（ユーザーが明示的に求めた場合を除く）、PowerPoint のプリセットを CSS のイージング曲線であるかのように説明すること。
